# Тестовое задание «Матчи тура»

Задача пользователя — сдать рабочее приложение **и** показать, что он понимает код. Проверяющие смотрят на: работу экрана, обработку неочевидных данных, читаемость кода и, главное, на объяснения причин багов в `SOLUTION.md`. Поэтому ты не просто выдаёшь код: каждое решение сопровождай объяснением «почему», которое пользователь сможет пересказать своими словами.

Репозиторий: https://github.com/Interlabs22/test-app (шаблон). Стек: Expo SDK 57, React Native 0.86, React 19, TypeScript, без роутера, один экран. Запускается `npm run web`.

## Порядок работы

1. **Сначала прочитай реальные файлы** проекта (`README.md`, `AGENTS.md`, `src/**`, `data/matches.json`, `SOLUTION.md`). Репозиторий мог измениться — не полагайся только на этот скилл. Если файлов в сессии нет, попробуй `git clone` шаблона; иначе попроси пользователя прислать их.
2. **Следуй `AGENTS.md` репозитория:** версии Expo меняются, перед использованием Expo/RN API сверяйся с `https://docs.expo.dev/versions/v57.0.0/` и `https://docs.expo.dev/llms.txt`, а не с памятью. Пакеты ставь через `npx expo install <pkg>`. Не добавляй нативные модули, требующие dev build — приложение должно работать в Expo Go. Перед сдачей — `npx tsc --noEmit`.
3. **Проверь `MATCHES_URL`** в `src/config.ts`: в шаблоне там плейсхолдер `OWNER/REPO`. Адрес должен вести на `data/matches.json` в репозитории пользователя (raw.githubusercontent.com, ветка main, репозиторий публичный). Проверь `curl -I`; если 404 — скажи пользователю, что нужно подставить его `owner/repo` после создания копии, и упомяни это в `SOLUTION.md`.
4. **Делай работу маленькими шагами = коммитами** (нужно минимум 3–5, история важна). Предлагай план коммитов:
   1. `fix: useFavorites — иммутабельное обновление и includes`
   2. `fix: UpdatedAgo — считать от since, чистить интервал`
   3. `feat: загрузка матчей, типы, состояния loading/error/empty`
   4. `feat: карточка матча, форматирование даты, счёта, статуса`
   5. `feat: фильтр и подключение избранного`
   6. `docs: SOLUTION.md` (и отдельный коммит на доп. задание, если делаем)
   Пользователь коммитит сам; ты даёшь готовые сообщения.
5. **Объясняй баги прежде, чем исправлять.** Подробный разбор — в `references/bugs.md`. Попроси пользователя пересказать причину своими словами; помоги сформулировать, если не получается.
6. **Заполни `SOLUTION.md`** по шаблону из репозитория (подсказки — `references/solution-guide.md`).

## Что должно быть в экране (часть 1)

Чек-лист требований — сверяй по нему перед сдачей:
- загрузка с `MATCHES_URL`; состояния **loading / error + «Повторить» / empty**;
- карточка: хозяева, гости, счёт (если есть), дата и время **в часовом поясе устройства**, статус по-русски, звёздочка;
- фильтр **Все / Предстоящие / Завершённые** над списком;
- «Обновить» или pull-to-refresh + `UpdatedAgo` («Обновлено N сек назад», сбрасывается после успешной загрузки);
- понятные типы, названия, разбиение на компоненты (`MatchCard`, `FilterTabs` и т.п.), без `any`.

Детали данных и реализации, включая ловушки в `matches.json`, — в `references/data-and-screen.md`. Прочитай этот файл перед написанием экрана.

## Правила для ответа пользователю

- Объясняй простыми словами, как человеку, который знает React для веба, но не RN: `View/Text/Pressable/FlatList/RefreshControl`.
- Код давай целыми файлами с путями; после — 2–4 строки «что и почему».
- **Не выдумывай** содержимое раздела «Как я использовал ИИ» и затраченное время: спроси пользователя, какие инструменты он реально использовал и где ИИ ошибся. Допустимо предложить формулировки, но фактами управляет он. Честность здесь важнее красоты.
- Не раздувай объём: задание на ~1 час, лимит 2 часа. Дополнительно — **одна** вещь на выбор (см. `references/solution-guide.md`).
- Если что-то не успели — так и пишем в `SOLUTION.md`; это нормально по условиям.

## Финальная проверка перед сдачей

- [ ] `npm install && npm run web` с нуля стартует без ошибок
- [ ] `npx tsc --noEmit` чистый
- [ ] звёздочки не горят по умолчанию; первая добавленная — загорается; повторный клик — гаснет
- [ ] `UpdatedAgo` тикает, после «Обновить» сбрасывается на 0
- [ ] матч без даты (`startsAt: null`) не показывает 1970 год; 0:0 отображается как счёт
- [ ] ошибка сети → сообщение + «Повторить» работает
- [ ] `SOLUTION.md` заполнен: время, решения по статусам и данным, 2 бага своими словами, ИИ, что улучшил бы
- [ ] репозиторий публичный, ≥3–5 коммитов, ссылка отправлена в ответ на сообщение с заданием
