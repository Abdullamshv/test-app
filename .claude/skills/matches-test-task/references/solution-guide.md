2. **Что сделано и что не успел** — список по пунктам условия (загрузка, карточка, состояния, фильтр, обновление, звёздочки, баги) + честно, что осталось.

4. **Баги из части 2** — по 1–3 предложения «почему так происходило → что исправили» (источник — `bugs.md`, но формулировки должны быть пользователя):
   - Звёздочки: `indexOf` возвращает индекс (-1 — «нет»), а проверка `Boolean(...)` считала -1 истиной, а индекс 0 ложью; плюс `toggle` менял массив на месте и отдавал в `setState` ту же ссылку, поэтому React не перерисовывал. Исправлено `includes` и неизменяемым обновлением.
   - UpdatedAgo: интервал создавался один раз и запомнил `seconds = 0`, поэтому всегда ставил 1; `since` не использовался; интервал не очищался. Теперь секунды вычисляются от `since`, интервал чистится и пересоздаётся при смене `since`.
5. **Как я использовал ИИ** — реальные инструменты; 1–3 случая, когда ИИ ошибся/дал неполный ответ и как это заметили; как проверял результат (запуск, смена пояса, тесты кликов, `tsc`). **Только правда** — спроси пользователя. Типичные настоящие примеры, которые стоит проверить, если они действительно были: забыл `extraData` у FlatList; `new Date(null)`; не проверил `res.ok`; нативный модуль, не работающий в Expo Go; версия API Expo не из SDK 57.
